# Threat Modeling and Risk Assessment

## Overview

This repository contains practical projects and lab exercises completed as part of the **Threat Modeling and Risk Assessment** module. The objective is to identify potential security threats during the system design phase, assess associated risks, and recommend effective security controls using industry-recognized methodologies.

The projects apply structured threat modeling techniques to real-world systems, enabling the identification of vulnerabilities before implementation and supporting a secure-by-design approach.

## Topics Covered

* Threat Modeling Fundamentals
* Data Flow Diagram (DFD) Design
* Trust Boundary Identification
* STRIDE Threat Analysis
* Risk Identification and Assessment
* Risk Prioritization
* Security Control Recommendations
* Mitigation Planning
* Secure System Design Principles

## Skills Demonstrated

* Threat Modeling
* Security Architecture Analysis
* Risk Assessment
* STRIDE Methodology
* Data Flow Diagram (DFD) Development
* Secure-by-Design Principles
* Cybersecurity Documentation
* Technical Risk Analysis
